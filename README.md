# 民宿服务信息管理系统

面向单体/多门店民宿的预订与运营管理系统，覆盖 **用户预订端 → 前台接待 → 住中服务 → 房务保洁 → 结算售后** 的完整业务闭环。

## 核心设计要点

1. **民宿 / 房型 / 实体房间三段拆分**，不再把房源信息堆在一张表里。
2. **按入住日期计算房晚库存**，用唯一约束防止同一房间同一天被重复预订。
3. **预订状态、支付状态、房间运营状态三套状态机分离**，互不覆盖。
4. **价格、住客、房型、取消规则、押金规则在下单时快照**，后续改价不影响历史订单。
5. **用户端与管理端独立构建**，后端按业务模块组织，不照搬若依的大而全结构。
6. **身份证应用层加密**（AES-256-GCM + HMAC 去重 + 脱敏展示 + 权限审计）。

## 规划技术栈

| 层 | 选型 |
|---|---|
| 后端 | Java 21、Spring Boot 3.x、MyBatis-Plus、Sa-Token、Flyway |
| 数据库 | MySQL 8（Redis 可选） |
| 前端 | Vue 3 + TypeScript + Vite + Pinia，用户端 / 管理端分离 |
| UI | Element Plus（管理端）、移动优先组件（用户端） |
| 测试 | JUnit 5、Testcontainers、Vitest、Playwright |
| 部署 | Docker Compose + Nginx |
